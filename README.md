# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/your-username/TransitOps.git
```

---

## Frontend

```bash
cd client

npm install

npm start
```

---

## Backend

```bash
cd server

npm install

npm start
```

---

# 🌐 Environment Variables

Create a `.env` file inside the server folder.

```
PORT=5000

MONGO_URI=YOUR_MONGODB_CONNECTION

JWT_SECRET=YOUR_SECRET_KEY
```
