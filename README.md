# 🚛 TransitOps - Smart Fleet Management System

TransitOps is a full-stack MERN application that helps organizations efficiently manage their transportation and fleet operations. It provides vehicle management, driver management, trip tracking, fuel records, maintenance tracking, expense management, analytics, and reports in one centralized dashboard.

---

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/your-username/TransitOps.git
```

---

## Frontend

```bash
cd client

npm install

npm start
```

---

## Backend

```bash
cd server

npm install

npm start
```

---

# 🌐 Environment Variables

Create a `.env` file inside the server folder.

```
PORT=5000

MONGO_URI=YOUR_MONGODB_CONNECTION

JWT_SECRET=YOUR_SECRET_KEY
```
